上一篇盘点了市面上的独立 DDS 芯片，前几篇又拆了 MSP430FR6047 的发射模块（PPG → 4 Ω PHY → 换能器）。这两个东西名字都不带"发射"，干的活却高度重叠——都是在"定时定点给负载递一个可控波形"。那到底有什么区别？为什么一个偏要用独立 SPI 芯片，另一个把发射器焊死在 MCU 里？这篇直接拉出来对比。

先把话说在前头：**DDS 是"通用波形合成"，MSP430FR6047 的 PPG 是"计量脉冲激励"**。前者追求"频率任意、相位可编程、波形干净"，后者追求"时间确定、频率相干、驱动够猛"。这不是同一个问题，答案自然不互通。

| 维度 | 独立 DDS 芯片（AD9833/AD9850/AD9910…） | MSP430FR6047 发射模块（PPG+PHY） |
|------|----------------------------------------|----------------------------------|
| 定位 | 通用信号源/本振/时钟生成 | 计量专用：超声换能器 burst 激励 |
| 输出形态 | 模拟正弦/三角/方波（DAC 电流输出+外部滤波） | 数字方波脉冲串（0/1），直接压换能器 |
| 波形灵活度 | 极高：连续频率/相位可编程，可 RAM 回放任意波形 | 低：方波脉冲串，激励 1~127 + 停振 0~15 个 |
| 频率范围 | AD9833 到 12.5 MHz；AD9910 级到 400 MHz | 约 133 kHz ~ 2.5 MHz |
| 频率分辨率 | 由 FTW 位数+时钟决定，AD9833 28-bit（mHz 级） | 1 个 HSPLL cycle，1 MHz 附近约 12.7 kHz 一跳 |
| 频率准确度 | 由外部参考时钟决定（可做到很"任意"） | 由 HSPLL 决定，只挑 (HP,LP) 组合的最近值 |
| 采样相干性 | 与外部采样无天然联系（需自己共享时钟） | 天生与 SDHS 采样/ASQ 时序**同源相干** |
| 负载驱动 | 电流型 DAC，几个 mA（AD9850 约 10 mA） | 输出阻抗低至 4 Ω、瞬态约 120 mA |
| 控制口 | SPI 寄存器（FSYNC/FQ_UD 触发），高速件加并行口 | 片内 SAPH 寄存器，软件/定时器/ASQ 三选一触发 |
| 功耗量级 | AD9837 8.5 mW ~ AD9910 数百 mW | 整机计量流程约 3 µA 账单（发射只是其中一环） |
| 集成度 | 独立芯片 + MCU + 晶振 + 重建滤波 | 发射、采样、时序、DSP 同在一颗 MCU |
| 适用 | 信号发生器、本振、扫频、时钟、DIY | 超声水/气表 ToF 流量计量 |

## 一、都是"数字合成波形"，路线却完全相反

DDS 的链路是教科书式的：**NCO（相位累加器）→ SIN ROM → 高速 DAC → 低通重建**。它的最低层愿望是"在数字域把相位算准，然后变成干净的正弦电压"。相位累加器每时钟往上加一个 FTW，查找表输出对应的幅度，DAC 把它转成模拟信号——所以它能连续输出任意频率的正弦，还能做相位/幅度/FSK/PSK 调制。

MSP430FR6047 的 PPG 完全不是一个思路：它连 DAC 都不要。PPG 就是一个**可编程的数字脉冲串生成器**：SAPHPGLPER/SAPHPGHPER 各写 N 个 HSPLL cycle，输出就是一组 50% 占空比的方波脉冲。波形"滤波整形"这一步不是由片内 DAC 做的，而是**由压电换能器本身**完成的——换能器是高 Q 谐振体，本身就只对共振频率附近的基波有反应，喂一串方波，它自然震出正弦；喂连续正弦，反而是浪费。

```
DDS:         数字相位 ──▶ SIN ROM ──▶ DAC ──▶ 模拟正弦 ──▶【外部LPF】──▶ 负载
MSP PPG:     数字脉冲串(0/1) ──▶ PHY 低阻驱动 ──▶【换能器高Q天然滤波】──▶ 声波
```

一句话：DDS 用"硅上的 DAC + 片外 LPF"做滤波，MSP430FR6047 用"换能器物理器件"做滤波。

## 二、频率：谁更"准"，谁更"对"

这是两者最被误解的差异，值得拆开。

**DDS 追求"准"——频率分辨率的精度。** 频率分辨率 = MCLK / 2^FTW。AD9833 是 28-bit，25 MHz 时钟下能调到 0.1 Hz；AD9910 是 32-bit，1 GSPS 下仍有 0.23 Hz。对信号源、跳频本振来说，"我要 1.000123 MHz 就能给 1.000123 MHz"，还能在微秒级换频，这是 DDS 存在的全部意义。

**MSP430FR6047 追求"对"——频率要与采样相干。** 它的发射频率公式是：

```
f_pulse = f_HSPLL / (HP + LP)
```

HP/LP 是 PPG 的相位周期数，以 HSPLL（68~80 MHz）周期为格。于是频率分辨率受限于"1 个 HSPLL cycle"：1 MHz 附近把其中一格 +1，频率就跳约 12.7 kHz——它给不了"任意频率"。

但注意另一个事实：**这颗 HSPLL 同时喂 PPG、SDHS 采样和 ASQ 时序**。发射频率和采样率是同源的。这意味着每次测量，采样网格相对发射相位是**固定的、可复现的**——回波信号每次落在相同相位位置，匹配滤波、相干平均、LEA 的 ps 级次样本插值才有意义。这是 ToF 计量精度链条的地基。DDS 想达到同样效果，必须让发射参考时钟和采样时钟共享并锁相，而 DDS 本身不提供也不关心这种相干性——它只对"输出频率对 FTW 的准确响应"负责。

> 结论：DDS 的"准"是绝对频率的准；PPG 的"对"是相对采样相位的对。计量在乎后者，信号源在乎前者。这也是为什么 Design Center 里会用 Frequency Sweep 去挑"回波幅度最大的激励频率"——它找的不是"数学上最准的频率"，而是"让物理计量系统最健康的频率"。

## 三、波形：正弦 vs 脉冲串——换能器不想要"完美正弦"

换能器是储能型高 Q 谐振体，起振要"踢它一脚"而不是"轻轻推"。PPG 的爆发式设计正好对齐这个物理：

- 激励脉冲 1~127 个，让换能器在共振频率被反复踢到满幅；
- 可选停振脉冲 0~15 个、与激励相位差 180°——最后一脚反着踢，给余振"急刹车"，缩短盲区；
- 波形是方波而非正弦，靠换能器自身的滤波特性在流体里重建声正弦。

DDS 也能供给换能器（DDS→功放→换能器的经典超声emitter 架构），例如需要 MHz 级扫频激励、或是频率超过 PPG 上限时。但 DDS 输出正弦/任意波形意味着外部还要加：功率缓冲（DAC 电流只有几个 mA）、阻抗匹配、以及——回到上一节——把 DDS 和接收采样时钟同源的工程复杂度。

## 四、驱动：几个 mA vs 120 mA/4 Ω，通用与专用的分水岭

最悬殊的差异在这里。DDS 的输出是**电流型 DAC 输出**，满幅只有个位数 mA：AD9834 满幅约 3 mA、AD9850 约 10 mA（RSET=3.9 kΩ）。它面向的负载是 50 Ω 传输线、ADC 时钟输入这类高阻抗/低功耗负载，后面要接外部放大器和阻抗变换。

MSP430FR6047 的 PHY 则直接对标压电换能器这种"大电容 + RLC 谐振枝"的凶悍负载：

- 输出阻抗可低至 **4 Ω**——源阻抗要远小于负载阻抗，否则 1~2 MHz 下换能器大电容的充放电边沿爬不上去，脉冲幅值被负载吃掉；
- 瞬态驱动电流最高约 **120 mA**；
- 片上自带终端匹配与 ATE 出厂 trim，把 CH0/CH1 两路电子阻抗配平到规格内——这是 Zero-Flow Drift（ZFD）对称性的物理根基。

> 本质差异：DDS 是"把波形信号生成给你，剩下的驱动你自己解决"；FR6047 的 PHY 是"连负载的脾气（电容、谐振、对称性）都替你考虑好了"。通用与专用的分水岭，就在驱动这一级。

## 五、控制与同步：SPI 配置口 vs 片内 ASQ 时序机

- **DDS**：通过 SPI 写寄存器（FTW/POW/控制字），语义上是"从外部总线配置一台独立仪器"。要等 FSYNC 帧（AD983x）、FQ_UD（AD9850）、I/O_UPDATE（AD9954/9910）这类"生效触发器"拉一下才真正应用配置。高速件（AD9910+）还要并行口来喂实时数据，配合外部 FPGA。
- **MSP430FR6047**：发射寄存器全部在片内（SAPHPGC/LPER/HPER/CTL/OSEL/PPGTRIG），写寄存器就是配置本地硬件。触发有三级选择——软件写 PPGTRIG、定时器边沿、或交给 **ASQ 时间标记**编排（先拉起 TX/RX 偏置 → 触发 PPG → 给 SDHS 上电 → 开采样窗口 → 反向重启）。整个收发序列 CPU 可以睡，这就是"约 3 µA 计量账单"能成立的原因。

独立 DDS 方案要等多久采样窗口打开、偏置稳定、通道切换，全是主机软件的责任，任何 ISR 抖动都会漏进时序。FR6047 把"发射打一炮"这件事做成了硬件自动化的一个环节。

## 六、功耗与集成：独立器件 vs 片上模块

DDS 单看功耗不吓人（AD9837 8.5 mW、AD9833 12.65 mW），但它只是发射链的一小块：你要为它配 MCU、参考晶振、重建滤波、输出缓冲，整条链路的硅面积、封装、电源域、BOM 都算进去，才公平。AD9910 这一级规矩是"仪器级功耗"（数百 mW），更是另一回事。

FR6047 的发射模块是 MCU 里的一个外设：不需要独立封装、独立电源、独立晶振（和采样/时序共享 HSPLL），发射完进掉电，整个测量周期（激励+接收+LEA 运算）的账单量级在微安。计量产品一年都靠电池，这是决定性差异。

## 七、什么时候该用谁（以及怎么混用）

| 你的场景 | 选谁 |
|---------|------|
| 台式/手持信号发生器、可编程本振、时钟、扫频源 | **DDS 芯片** |
| MHz 级精细扫频找"换能器甜蜜点"（比 PPG 的粗步进细得多） | **DDS 芯片**做离线扫频工具 |
| 频率高于 2.5 MHz 的超声激励（PPG 覆盖不到） | **DDS + 功放**，但要解决时钟同源 |
| 超声水/气表的 ToF 连续计量、相干采样 | **MSP430FR6047 片上发射** |
| 需要两路对称、低漂移的激励（ZFD 敏感场景） | **MSP430FR6047 片上发射**（有 ATE trim 配平） |
| 超低功耗、CPU 可睡的全自动采集 | **MSP430FR6047 片上发射**（ASQ 牵头） |
| FPGA/MCU 搭自研超声系统，发射与采样同参考时钟 | DDS + 外部共享时钟/分频锁相，工程自担 |

值得单独说一句的是"混用"：FR6047 的 Design Center 本来就带 Frequency Sweep 概念——找一个换能器的甜蜜点频率写回配置。若换能器工作点微妙、或依赖非常规激励，完全可以用一颗 DDS 作为**标定级扫频源**找出谐振点，再把它映射回 PPG 可用的 (HP,LP) 组合。DDS 负责"找到对的频率"，PPG 负责"用对的方式发出去"。

## 八、总结：这不是升级，是分工

DDS 芯片与 MSP430FR6047 发射模块不是"谁取代谁"的关系，而是同一类问题（数字合成驱动信号）的两个极端解：

- **DDS 把灵活性做到极致**：任意频率细步进、任意波形、外置驱动，代价是相干性、时序、驱动、功耗全靠你自己补齐；
- **MSP430FR6047 把确定性做到极致**：频率与采样同源、ASQ 硬件编排、低阻 4 Ω/120 mA 驱动、芯片级两路配平、微安级账单，代价是频率范围和波形自由度被锁死在计量这个用途。

套用发射模块那篇的话：**计量发射器不追求"打得响"，追求"打得确定"**——而 DDS 的哲学恰恰是"打得任意、打得准、打得花"。搞清你要的是"确定"还是"任意"，答案自己就出来了。
