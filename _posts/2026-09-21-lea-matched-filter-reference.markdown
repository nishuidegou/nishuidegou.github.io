前几篇拆完发射链和 LEA，有一个问题值得单独写清楚，因为它最容易误解：**LEA 做相关性计算时，参考信号是用 PPG 发出的计量脉冲串对准的么？**

答案是否定的。LEA 匹配滤波的参考信号**不是** PPG 输出的方波脉冲串，而是**片上预存的一段理想正弦波 burst 模板**。这篇说明为什么，以及真正的"参考"到底由谁提供。

## 一、两条链路上的对象不一样

```
发射链：PPG 方波脉冲串 → PHY → 换能器(高Q带通整形) → 水里传播 → 回波
                                                                  ↓
接收链：回波 → SDHS 采样 → LEA 匹配滤波（相关）← 参考信号：正弦模板
```

PPG 的方波脉冲串只存在于**驱动链路**里。它被换能器的谐振特性过滤之后，到水里、再到接收端耳朵里的已经是**近正弦的 burst**。所以信号处理级的"参考信号"应当对应"期望接收到的真实波形"，而不是驱动端的原始方波。

## 二、参考信号是"正弦模板"，且与激励频率对齐

- 匹配滤波（matched filter）原理：接收信号 `r(t)` 与期望有用信号的模板 `s(t)` 做相关，**相关峰的位置就是到达时刻**。前提是模板的频谱形状真实代表有用信号，才能得到最大输出信噪比。
- 这里的模板 `s(t)` 是一段**固定频率的正弦 burst**，系数以数组形式存放在片外/片内 flash，运行时交给 LEA 做 FIR/FFT 形式的匹配滤波。
- **模板频率 = 激励频率 F1**。F1 由 PPG 的 (HP,LP) 组合决定，模板必须对齐这一频率，两者在频谱上才一致。这正是"相干"的第二层含义：**发射相位与模板相位都被锁定在同一个参考网格上。**

## 三、时间参考（起跑线）由谁定

LEA 相关输出的是一个**相对延迟**，但它并不知道"发射是何时开始的"。ToF 的 t=0 由另一件事决定：

- 发射触发时刻——ASQ 时间标记触发 PPG 的那一刻——就是 ToF 计时的起点；
- 采样网格与发射同源（共用同一颗 HSPLL），因此回波落在采样网格上的位置是固定刻度、可复现的；
- LEA 在这个固定刻度上做匹配滤波找到相关峰 → 得到精确到达相位 → 顺流/逆流两发取差 → dToF → 流量。

所以完整的关系是：

```
相关性 = 相关(回波样本, 正弦模板)，t=0 来自发射触发（PPG/ASQ），两者由同源时钟绑定
```

也就是说：**参考信号是正弦模板，时间基准是发射触发，纽带是同一个 HSPLL/激励频率**——而不是拿回波去和 PPG 的输出脉冲直接做相关。

## 四、如果真拿"方波脉冲串"当参考会怎样

方波的频谱是一堆奇次谐波叠加，而回波经换能器带通后只剩基波附近有能量。把方波当参考的话：

- 匹配滤波的"模板能量"大量落在接收信号没有的谐波上；
- 相关增益被稀释、SNR 变差；
- 相关峰变得更模糊、峰值位置抖动变大，直接伤害 ToF 精度。

这既是理论推导（参见 SLAA814）的结论，也是 USS 软件库坚持用正弦模板的工程原因。

## 五、一句话总结

**PPG 负责"把声波踢出去并在时间上定标"，LEA 负责"用正弦模板在定标好的网格上把回波找回来"——两者的纽带是同一个 HSPLL 时钟与激励频率，而不是彼此的输出直接互相相关。**
