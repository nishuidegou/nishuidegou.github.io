最近尝试了一种新的写作方式：**让 AI 生成 Markdown 文章，再借助工具排版后导入微信公众号**。不用再对着后台一点点调字号、调颜色，排版和内容彻底分离。这篇记录一下完整流程和踩过的坑。

## 一、完整流程一览

```text
AI 生成 Markdown
      ↓
粘贴到 Markdown 排版工具（doocs/md、MDPH 等）
      ↓
复制渲染好的富文本
      ↓
粘贴到公众号后台编辑区
      ↓
补封面、摘要、预览手机端 → 发表
```

## 二、第一步：用 AI 生成 Markdown

给 AI 一个清晰的需求，通常包含这几部分：

- **文章类型**：活动记录、技术教程、读书笔记……
- **目标人群**：小学生家长、程序员、班级老师……
- **必含内容**：项目 / 章节 / 数据
- **风格要求**：口语化 / 正式 / 有趣

提示词示例：

> 请写一篇小学班级到奥体中心参加综合实践活动的公众号文章，题目「挑战自我，智慧闯关」，包含陆地冰壶、趣味飞盘、光电射击、工程搭建四个项目，同学们还会表演节目。要求用 Markdown 格式，图片位置用占位符表示。

生成后得到的就是一份结构清晰的 `.md` 文件，方便二次编辑和版本管理。

## 三、第二步：选择 Markdown 排版工具

常用工具对比：

| 工具 | 特点 | 是否免费 |
| --- | --- | :---: |
| doocs/md | 开源，样式丰富，支持目录/代码配色 | 是 |
| MDPH | 在线即用，导出方便 | 是 |
| wechat-format | 本地渲染，可控性强 | 是 |

操作几乎一样：**把 Markdown 粘贴进去 → 左侧编辑、右侧预览 → 点"复制"得到富文本**。

## 四、第三步：导入公众号后台

在公众号编辑器里直接粘贴即可，标题、引用、表格、代码块都会带样式。

需要注意几点：

1. **图片要单独处理**：后台粘贴不支持带图，需要逐张上传或用素材库地址替换 Markdown 里的图片链接
2. **代码块**：检查横向滚动是否正常，超长代码建议换行显示
3. **字号与边距**：不同工具默认值不同，可在工具里微调后另存模板

## 五、常用技巧

- **图片占位**：先用 `https://via.placeholder.com/800x400?text=说明文字` 占位，后期替换成真实图片
- **保留 Markdown 源文件**：排版不好的时候，改源码重排比在后台改快得多
- **固定模板**：把标题、强调色、引用样式存成自己的模板，风格统一

## 六、结语

AI 负责生成内容，Markdown 负责结构化，工具负责排版，公众号负责分发——各司其职，写作效率提升明显。

如果你也在写公众号，不妨试试这套流程。
