上一篇讲了 USCT 的原理和反演的"三层楼"。这一篇落到工程：**怎么把 USCT 的"前向问题"——声波在非均匀介质里怎么传播——用 COMSOL 跑出来，得到能喂给反演算法的合成数据。**

先说结论，免得期待错位：COMSOL 不是拿来替代 k-Wave 的。它适合做**少量高保真算例**——验证自写求解器、研究衰减/密度/换能器指向性这些具体效应、或者给反演算法造一批"真值"数据；但如果你想跑全波形反演那种"每源每频成千上万次求解"的大循环，COMSOL 会很吃力（原因在第八节）。

本文按建模的自然顺序走：**先定目标 → 选物理场 → 搭几何 → 设边界 → 填材料 → 划网格 → 加激励 → 选求解器 → 后处理 → 避坑**。中间用一个可复现的二维算例把关键参数串起来。

> 说明：本文用 Python 自写的二维 Helmholtz 有限差分解生成了两张示意图（方程与 COMSOL 的 *Pressure Acoustics, Frequency Domain* 完全一致），用于说明"模型长什么样"和"波场长什么样"。COMSOL 的 GUI 步骤和参数按正文给出，复现时对照即可。菜单名称视 COMSOL 版本略有差异。

## 一、先想清楚：用 COMSOL 仿真 USCT 到底要得到什么

USCT 的完整流水线是"**采集 → 前向建模 → 反演 → 成像**"。COMSOL 站在"前向建模"这一格，产出有三类用途：

| 用途 | 产出 | 为什么用 COMSOL |
|------|------|----------------|
| 造合成数据 | 各阵元接收到的波形 / 走时 | 几何和材料可控，有真值可对照 |
| 效应研究 | 单独开/关衰减、密度、耦合层 | 物理量可独立开关，因果清楚 |
| 验证自写求解器 | 同算例对照波场/走时 | 商业软件网格与求解器更成熟，当基准 |
| 换能器建模 | 含压电、流固耦合的声场 | 多物理场耦合是它的强项 |

**不适合的**：FWI 那种把 COMSOL 套进优化循环跑几万次。所以现实的分工通常是——**COMSOL 造"标杆"数据，k-Wave/自写求解器批量造训练和反演数据**（第十二节细说）。

## 二、选哪个物理场接口

USCT 的核心是声波传播，最直接的接口是声学模块里的：

**Pressure Acoustics, Frequency Domain（压力声学，频域，`acpr`）**

它解的正是时谐亥姆霍兹方程（变密度形式）：

$$
\nabla\cdot\left(-\frac{1}{\rho}\nabla p\right) - \frac{\omega^2 p}{\rho c^2} = q
$$

其中 $p$ 是复声压，$\rho$ 是密度，$c$ 是声速，$\omega = 2\pi f$，$q$ 是源项。**把 $c$ 取成复数 $c(1+\mathrm{i}\alpha)$ 就自然带上了衰减**。

不同需求对应不同接口：

| 需求 | 接口 |
|------|------|
| 单频/扫频稳态场、要和 FWI 的频域框架对齐 | Pressure Acoustics, Frequency Domain |
| 宽带脉冲、要看成时波形 | Transient Pressure Acoustics 或 Time Explicit |
| 微小尺度、黏热损耗重要 | Thermoviscous Acoustics |
| 换能器电-机-声全链 | Piezoelectricity + Acoustic-Structure Interaction |
| 弹性固体（骨、探头壳） | Solid Mechanics / Elastic Waves |

**频域 vs 瞬态怎么选**：USCT 反演（尤其 FWI）大量在频域做，频域直接求解器还能对"同一频率、多个源"复用矩阵分解，所以**建模阶段优先频域**；真要宽带时域波形，再用瞬态。

## 三、几何与阵列：二维、轴对称还是三维

- **二维（2D）**：最快，适合跑通流程和算法验证。环阵在这里就是一"圈"换能器，物理上相当于无限长圆柱，和真实三维有偏差，但趋势和算法完全可用。
- **轴对称（2D axisymmetric）**：只有几何和场都绕轴旋转对称时才成立。**环阵绕轴转一圈不是对称的**（源在某个方位角上），所以整套 USCT 不能用轴对称，除非你做的是"绕轴扫描的单个源"的简化。
- **三维（3D）**：最真实，也最贵。分辨率、层间效应、真实阵列指向性都要它。建议先用 2D 定算法，再上 3D 做少量验证。

几何按"同心层"搭最省事：

```
最外层：PML 吸收层        ← 模拟无界水槽，吸掉向外跑的波
   ↓
水耦合层（c≈1500 m/s）
   ↓
被测体（幻影 / 真实断面）  ← 里面再放脂肪、腺体、病灶等子域
```

环阵换能器用**参数化**方式生成：定一个半径和阵元数 $N$，用 `Array` 或脚本循环放 $N$ 个点/线源。**不要手工摆几十个源**——用 COMSOL 的 `Array` 数据集或 LiveLink for MATLAB 生成，改一个参数就能重建整个阵列。

## 四、边界条件

- **PML（完美匹配层）**：外圈必须加，否则边界会把波反射回来，把数据彻底污染。典型厚度取**几个波长**（2D 算例里约半个到两个波长就够），类型用 Cartesian 或 Polynomial。PML 的厚度和吸收参数不当，会残留反射——这是最常见的坑（见第十一节）。
- **平面波辐射 / 远场**：如果只想算远场散射，可以用辐射边界代替 PML。
- **内部界面**：水-组织、组织-组织默认是"声压连续、法向位移连续"。**真实的水-皮肤有阻抗失配**，想研究这个，就把皮肤单独建成一层，或者在界面加一层薄的过渡。
- **声-固耦合**：涉及探头匹配层、骨头时才需要，普通软组织流体模型不需要。

## 五、材料参数

二维算例你就需要一个材料表（数值为代表性典型值）：

| 材料 | 声速 $c$ (m/s) | 密度 $\rho$ (kg/m³) | 衰减 (dB/cm/MHz) |
|------|---------------|--------------------|------------------|
| 水（耦合/水槽） | 1500 | 1000 | ~0.002 |
| 脂肪 | 1450–1460 | 950 | ~0.5 |
| 纤维腺体 | 1540–1570 | 1040 | ~0.7 |
| 皮肤 | ~1600 | 1150 | ~1.0 |
| 病灶（偏高） | 1580–1620 | — | ~0.9–1.2 |

**两个必须小心的地方**：

1. **衰减单位**。文献到处在混用 dB/cm/MHz 和 Np/m，转换关系是 $1\ \text{Np/m} \approx 8.686\ \text{dB/m}$。输进 COMSOL 前先统一。
2. **复声速与时谐约定**。用 $c' = c(1+\mathrm{i}\alpha)$ 表达衰减时，COMSOL 的时谐因子（$e^{\mathrm{i}\omega t}$ 还是 $e^{-\mathrm{i}\omega t}$）决定虚部的正负号。**符号搞反，衰减会变成指数增长**，波场会在边界爆掉。拿一个均匀同名算例验证一遍再往下做。

## 六、网格：由最高频决定

有限元网格的经验规则：**每个波长至少 6–10 个单元**。波长 $\lambda = c/f$，所以网格尺寸由**最高频率和最小声速**共同决定：

$$
h \le \frac{\lambda_{\min}}{6} = \frac{c_{\min}}{6 f_{\max}}
$$

举例：$f_{\max} = 1$ MHz、组织最小声速 1450 m/s，则 $\lambda_{\min} \approx 1.45$ mm，网格 $h \lesssim 0.24$ mm。**声速高的地方波长大、可以粗；声速低的地方要加密**。另外 PML 里至少也要每波长若干单元，否则吸收效果差。

## 七、激励与"扫一圈"

- **源**：频域里点源、线源、边界源都可以。真实阵元有尺寸和指向性，想研究就建成一小段线源或带 apodization（幅度加权）的线源。
- **幅相**：想模拟编码激励，就把源的复幅值设成对应的相位序列。
- **扫一圈**：这是 USCT 仿真的核心操作。有两种做法——
  1. **LiveLink for MATLAB + for 循环**：改源位置/编号 → 求解 → 导出，脚本自动跑完 $N$ 个源。最灵活，推荐。
  2. **Study 参数扫描**：把源位置做成参数，一次提交扫完。省事，但每个参数点各解一次，内存和时间要预留。
- **接收**：用 `Domain Point Probe` 或 `Boundary Point Probe` 在所有接收阵元位置提取复声压；扫频时 probe 会自动给出每条频率的结果。

## 八、求解器：频域直接法的关键红利

频域用**直接求解器**（MUMPS / PARDISO）：

- 一次矩阵分解（LU）后，**同一频率换不同源只做回代**，多个源共享一次分解——这是频域相对时域的最大红利，USCT 的多源正好吃满。
- 扫频时，每个频点各分解一次，频点越多、内存和时间越高。
- 规模估计：2D 几十万自由度很轻松；3D 动辄千万自由度，直接法的内存会迅速顶到几十上百 GB，所以 3D 要么降频点、要么换迭代求解器、要么干脆用 k-Wave。

## 十、后处理：从波场到反演输入

从 COMSOL 拿到复声压后，喂给反演算法前还要做几件事：

1. **提取接收信号**：把各 probe 的复声压按阵元排列成"道集"（source × receiver × frequency）。做时域波形就对频域结果做逆傅里叶变换。
2. **拾取走时**：如果反演用的是走时层析，就在波形上拾取初至（first arrival）。
3. **加噪声**：合成数据太干净会误导算法，按目标信噪比加高斯/乘性噪声。
4. **对齐约定**：确认源的时间零点、幅度量纲、时谐符号、衰减符号和你的反演代码一致——**这一步不做，前面全白算**。

## 十一、COMSOL 仿真 USCT 的常见坑

1. **PML 不够厚 / 参数不当**：残留反射会伪装成"散射信号"，让反演出幽灵结构。用均匀介质算一遍，看边界回波是否低于目标信噪比。
2. **网格不足**：会有数值色散，相位误差随距离累积，直接毁掉走时和 FWI。做一次网格收敛测试（加密后结果变化应小于目标精度）。
3. **衰减单位与符号**：见第五节，最容易出错且最难发现。
4. **源项量纲**：点源的归一化方式影响幅度；反演通常只关心相对幅度/相位，但别在中间步骤混用两种归一化。
5. **换能器理想化**：点源假设忽略指向性和有限孔径，高角度信息会失真。研究阵列时务必建成有尺寸的线源。
6. **3D 内存爆炸**：先估自由度再开算，别到一半发现内存不够。
7. **时谐约定不一致**：频域解和你自写代码的 $e^{\pm\mathrm{i}\omega t}$ 不一致时，相位会整体反号。

## 十二、COMSOL vs k-Wave：怎么分工

| | COMSOL | k-Wave |
|---|---|---|
| 方法 | 有限元（频域/时域） | 伪谱时域（k-space） |
| 强项 | 多物理场、压电、流固耦合、频域多源复用分解 | 大批量时域前向、宽频、易脚本化、GPU |
| 弱项 | 大批量求解贵、3D 内存高 | 复杂换能器/多物理场建模麻烦 |
| 适合 | 少量高保真"标杆"数据、效应研究 | 批量生成训练/反演数据、三维前向 |

**实用路线**：用 COMSOL 造一批带真值的"高保真样本"来验证和标定你的自写/k-Wave 求解器，再用后者批量前向、跑反演。这也和我上一篇讲的"用经典方法做基线"是同一条纪律。

## 十三、小结

- COMSOL 仿真 USCT，核心接口是 **Pressure Acoustics, Frequency Domain**，解的就是那个亥姆霍兹方程，衰减靠复声速。
- 建模按固定顺序：**定目标 → 选接口 → 搭几何（同心层 + 阵元）→ 加 PML → 填材料 → 划网格（每波长 ≥6–10 单元）→ 设源与接收 → 频域直接法求解 → 后处理导出**。
- 频域直接法对"多源"复用矩阵分解，是它做 USCT 的隐藏优势。
- 它最适合当**高保真标杆**，批量前向和反演交给 k-Wave/自写求解器。
- 真正的坑集中在**PML 反射、网格色散、衰减单位与符号、时谐约定**四条上，先用均匀算例全部验证一遍再上幻影。
