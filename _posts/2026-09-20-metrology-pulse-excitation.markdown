上一篇文章把独立 DDS 芯片和 MSP430FR6047 发射模块拉到同一张台上对比，反复出现一个词：**计量脉冲激励（metrology pulse excitation）**。这篇把它单独展开，讲清楚三件事：它是什么、为什么计量必须这么干、以及它在 MSP430FR6047 上是怎么落地的。

先给结论：**计量脉冲激励不是"把波发出去"，而是把每一次发射都当成一次可复现的时间测量事件的起点。** 它关心的是声波到达的时间（ToF），不是声压大小——这决定了它和"通用波形合成"在本质上分道扬镳。

## 一、先定义：什么是"计量脉冲激励"

它不是稳定输出一个正弦波，而是按计量节拍，**在精确时刻、用精确频率、发一串（burst）固定的方波脉冲去"踢"压电换能器**，等回波，然后重复。每次激励都是离散的、可复现的——因为它是被测"飞行时间"的起跑线。

```
激励脉冲串(1~127) ┐ 停振(0~15)        回波
 ██ ██ ██ ██ ██ ██ ███ ██████          ∿∿∿∿∿
 |←─ burst ─→|←余振衰减→|←gap→|→ ADC 接收窗口 →|
```

## 二、为什么计量必须用脉冲、而不是连续正弦

1. **脉冲串才有清晰的时间参考点**。连续波要靠"零相位点"当起跑线，相位漂移和频率误差会直接折算成时间误差；而一个脉冲串的**首沿**是干净、可重复的时间标记。
2. **收发互斥**。流量计一发一收、换能器时间复用。FR6047 里就是 PHY 的 MUX 在 CH0/CH1 之间切换顺流/逆流两发。连续发射会让收发打起来，脉冲 burst + 接收窗口的时序划分是硬件自动化正常工作的前提。
3. **回波按"每一次激励"一一对应**，可以做相干平均、匹配滤波；连续波无法从噪声里干净地抠出到达相位。
4. **省能量**。占空比发射，把驱动能量投在需要的时间窗里，而不是持续耗电。

## 三、换能器物理：高 Q 谐振体怎么被"踢"响

压电换能器等效是"大电容 + RLC 谐振枝"的储能体，Q 值很高。它的脾气决定了激励方式：

- 只有**靠近其谐振频率**的分量能转成有效振动，其他频率基本被反射/吸收；
- 起振靠**蓄能**——单个脉冲能量太弱，必须在谐振频率附近**连续踢多下**（相参累积）才能把振幅顶到满；
- 停振后不会立刻安静，按自身 Q 值**余振（ring-down）**，余振会盖住近距离回波，形成**近端盲区**。

所以"把换能器激励好"的标准答案是一串**频率≈换能器中心频率的方波脉冲**：方波里的高次谐波由换能器自身滤波掉，谐振体的物理特性替你做完了"波形整形"。这正是"换能器不想要完美正弦"的原因——喂一串恰到好处的方波比喂连续正弦更高效。

## 四、脉冲激励的三要素

### 4.1 激励频率：对准阻抗最低点

激励频率要贴近换能器的**阻抗最低/灵敏度最高点**。偏离它，阻抗猛涨、回波幅度暴跌。FR6047 里发射频率由 PPG 的高/低相位周期数决定：

```
f_pulse = f_HSPLL / (HP + LP)
```

HSPLL 由片外 4~8 MHz 参考（USSXT）锁到 68~80 MHz，HP/LP 是以 HSPLL 周期为格子的"高/低相位长度"。因为一格就是 1 个 HSPLL cycle，频率分辨率受限于此：1 MHz 附近把某一相位 +1 cycle，频率就跳约 12.7 kHz。所以激励频率几乎无法取任意值，只有在 (HP,LP) 组合里挑**最接近换能器中心频率**的那一组。Design Center 的 Frequency Sweep 就是逐点扫 F1、看哪个频率下回波幅度最大，把"甜蜜点"写回正式配置。

### 4.2 脉冲个数：能量 vs 时间窗的平衡

- 太少 → 蓄能不足、回波太弱，信噪比不够；
- 太多 → burst 拉长、挤占接收窗口，对近距离回波（管壁直通波）干扰；
- 还直接影响功耗：占空比翻倍，平均电流跟着翻倍。

FR6047 的范围是激励脉冲 **1~127 个**，软件里对应 `numOfExcitationPulses`。

### 4.3 停振脉冲：给余振"刹车"

计量脉冲激励最有意思的细节之一。发射完同相脉冲后，可以**紧跟 1~15 个相位反 180° 的脉冲**（`numOfStopPulses`）——等于在余振快结束时反着踢一脚，主动抵消残余振动：

- 缩短 ring-down → 缩短盲区、允许更短的收发间距（气体、短量程场景很关键）；
- 让接收窗口起始段更干净，回波首沿更清晰。

刹多重、刹多快，取决于换能器 Q 值和收发距离，需要实验标定。

## 五、相干性：脉冲激励的命门

这条决定计量精度为什么能做到 ps 级。**FR6047 的发射、采样、时序全部共享同一颗 HSPLL**：

```
USSXT(4~8MHz) → HSPLL(68~80MHz) ──┬─→ PPG(发射频率)
                                  ├─→ SDHS(采样率)
                                  └─→ ASQ(时间刻度)
```

含义：每次测量，**采样网格相对发射相位是固定的、可复现的**。回波每次都落在相同的相位位置，于是可以：

- 相干平均去噪；
- 匹配滤波（LEA 来干）;
- 次样本插值有稳定的相位参考——ToF 的 ps 级分辨率就是从这里榨出来的。

如果发射用独立时钟（比如外挂 DDS），采样率与发射频率的微小失配会随时间累积成相位漂移，时间测量精度直接崩掉。这就是"计量脉冲激励"与"通用波形合成"最本质的分野。

## 六、在 MSP430FR6047 上的实现链路

```
请求 → ASQ 时间标记(t=0 起偏置, t=n1 触发PPG, t=n2 SDHS上电, t=n3 开采样窗)
              ↓
       PPG(脉冲串合成) → PHY(4Ω/120mA低阻驱动+MUX) → CH0/CH1 → 换能器
              ↓
     回波 → 同源采样(SDHS Σ-Δ) → LEA 匹配滤波/插值 → 两发dToF → 流量
```

各模块分工：

| 模块 | 干的活 | 关键寄存器/配置 |
|------|--------|-----------------|
| PPG | 数字脉冲串合成器 | SAPHPGC（脉冲数/停振数/极性/空闲电平）、SAPHPGLPER/SAPHPGHPER（相位长度）、SAPHPGCTL（使能/通道/触发源）、SAPHPGTRIG（软件扳机） |
| PHY | 低阻驱动 + 双通道 MUX | SAPHOSEL（把 PPGSE 引到 CH0_OUT/CH1_OUT）、SAPHCH0/CH1（终端匹配/trim） |
| ASQ | 硬件时序机，时间标记自动编排 | SAPHATM_A/B/C/D（各事件的时标） |

- **PHY 为什么是 4 Ω/120 mA**：换能器是"大电容 + RLC"的凶猛负载，源阻抗必须远小于负载阻抗，否则 1~2 MHz 下边沿爬不上去、脉冲幅值被负载吃掉。片上自带终端匹配与 ATE 出厂 trim，把 CH0/CH1 两路电子阻抗配平到规格内——这是 Zero-Flow Drift 对称性的物理根基。
- **ASQ 让 CPU 可以睡**：一次完整测量由时间标记把"TX/RX 偏置上电→触发 PPG→SDHS 上电→开采样窗→反向重启"排成一条自动流水线，CPU 发完指令就进低功耗。这是"约 3 µA 计量账单"能成立的原因。
- **一个硬约束**：`[Gap between pulse start and ADC capture]` 必须大于 SDHS 的建立时间（约 40 µs），否则 ADC 还没稳就开窗，前段全是建立期噪声——这也是配置报错的高发来源。

## 七、它怎么影响最终指标

- **首沿确定性**：靠同源固定相位网格，回波的到达相位抖动主要来自流动本身而非电子线路。这是"测流速"而不是"测发射机"的前提。
- **ZFD（Zero-Flow Drift）**：零流量时顺逆两发 ToF 应当相等，两发测得差全部来自"驱动源阻抗、换能器看到的电路阻抗"在两路的不对称。硅内侧由 ATE trim 配平，PCB 走线等长、外部元件对称由设计者补齐。
- **盲区与量程**：停振脉冲和 gap 的设定直接决定能以多近距离开始测量——小管径气体、短直管段的量程上限往往就卡在这。

## 八、对照 DDS 的一句话收尾

**DDS 把"想让换能器响"做成"任意波形、外置驱动、自己解决相干"；计量脉冲激励把同样的事做成"固定脉冲串、低阻大电流、硬件保证相干"。** 前者是通用仪器思维，后者是"把误差消灭在时间测量起源处"的计量思维——这就是上一篇"打得确定比打得响重要"这句结论的完整展开。
