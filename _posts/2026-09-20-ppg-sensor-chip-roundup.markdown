做可穿戴健康监测（智能手表、手环、血氧指夹、心率贴片），最省事的做法是选一颗**独立的 PPG 芯片**——一颗把"光源驱动、光电接收、放大、ADC、时序控制"全装进去、只留一个 I2C 或 SPI 总线口给主控的光学传感件。这篇把市面上主流方案按接口、形态、用途整理成表，并附选型和排坑要点。

先说清本次盘点的边界：**只收"自带数字接口（I2C/SPI）的独立 PPG 芯片/模组"**。MCU 内部集成的 PPG（比如高通/瑞萨可穿戴平台）、以及只有 LED+PD、没有任何接口的纯光学"前端"（如 OSRAM SFH 7xxx 系列、Broadcom APDS 系列），都不在表内，最后会单独提一句。

## 一、先分清："PPG 芯片"其实有三副面孔

| 形态 | 内含 | 代表 | 典型玩法 |
|------|------|------|----------|
| 完整模组 | LED + 光电二极管(PD) + AFE + 接口 | MAX30102、BH1790GLC、Si1145-M01 | 开箱即测，光学件不可换 |
| 半集成 AFE | 驱动 + AFE +（部分含 PD）+ 接口，LED 外接 | GH3011、AFE44xx、MAX8614x、ADPD410x | 光学设计自由度大，灯随你配 |
| 纯光学前端 | LED + PD，无 AFE 无接口 | OSRAM SFH7xxx、Broadcom APDS 等 | 必须外接自己的 AFE，不在本次范围 |

- **完整模组**的好处是省心：光学对位、遮光、驱动都替你排好了，适合快速出样和消费级手表；
- **半集成 AFE** 把"灯"的选择权交给你：绿光打心率、红+红外做 SpO2、RGB 做多通道，还能自定义 PD 面积/间距，是做产品时的主流，也是研究运动伪影算法的地基。

## 二、怎么读一颗 PPG 芯片的规格

几个"看名字会以为重要、实际要换个角度读"的参数：

1. **接口**：I2C（一般 400 kHz，慢但省脚）vs SPI（快、开销低、多条传感器共线友好）vs 引脚可选双接口。对单颗 PPG，I2C 带宽通常够用（400 kHz 足以跑满大部分原始数据流）；选 SPI 更多是总线拓扑原因。选型先看主控外设资源。
2. **波长**：绿光只够算心率（PPG 幅度大）；**SpO2 必须红光 + 红外两路**，用红光/红外交流比值的经验公式(R=AC_R/DC_R ÷ AC_IR/DC_IR)拟合血氧。想做血氧就别买单绿光件。
3. **ADC 位数**：标 18~24 bit 是"读出位数"，真正看信噪比的是**动态范围（dB）**——TI 的 22-bit 读数和 ADI 的 14-bit ADC 都能到 100 dB 左右，因为优秀的是模拟链路不是位数。
4. **FIFO 深度**：决定中断频率。FIFO 深 = 主控可以睡更久、被叫醒更少，漫游功耗大头在这。
5. **自主性（autonomous mode）**：芯片自己按周期采数、写 FIFO、中断叫主控，主控全程可睡——这是手环能把功耗压下来的关键。
6. **功耗模型**：平均电流 ≈ LED 峰值电流 × 脉宽 × 采样率 + 接收通道电流。标"30 µA"这种数字通常是 LED 不发光的接收电流，别误当整机功耗。

## 四、按用途选型的速查表

| 你的场景 | 推荐 | 理由 |
|---------|------|------|
| 快速出样 / 学习 / 演示 | **MAX30102** | 生态最全，几块钱研模块遍地，教程库最多 |
| 量产手环/手表（单绿光心率） | **BH1790GLC 或 GH3011** | 一个极省料、一个国产供货稳且自带算法 |
| 腕部高质量心率+血氧（消费旗舰） | **MAX86141** | 双 PD 通道对抗低灌注与运动，SPI 快 |
| 医疗级/临床指夹血氧 | **AFE4490 / AFE4403** | 大 LED 电流、故障诊断、全温区、110 dB |
| 研究性多模态（PPG+ECG、多波长、运动伪影） | **ADPD4100/4101 或 AFE4900** | 8 路输入/ECG 同步，灵活得像实验室仪器 |
| 极小尺寸（耳环、贴片、TWS） | **AFE4410 / AFE4900** | 2.6×2.1 mm QFN，功耗低，接口可选 |
| 双源/国产化需求 | **GH3011** | 汇顶原厂支持文档全，Pin 兼容选择多 |

## 五、接口之外，最容易踩的坑

1. **光学隔离是命门**：LED 直接照到 PD 的光（光学串扰）会吃掉 ADC 动态范围。完整模组把遮光做在封装里（如 MAX30102、BH1790GLC），用 AFE 自由设计时记得：PCB 上加挡光墙、PD 远离 LED、过孔灌封。
2. **环境光抑制别全指望芯片**：AC 环境光（日光灯 100/120 Hz）芯片能压（如 ADPD 60 dB、MAX8614x 70 dB），但 DC 环境光和强阳光仍然可能让 PD 饱和——用 ALC/offset DAC 把直流分量抽走，必要时加滤光片。
3. **运动伪影是算法问题，不是芯片问题**：芯片只给你原始 PPG。静息测量都好说，动态测量要靠加速度计 + 自适应滤波/多通道融合，选芯片前先想清楚自己拿不拿得出算法，否则"最好的芯片也测不准"。
4. **LED 供电要低噪**：LED 峰值电流动不动几十到两百 mA，直接抽在主 3.3 V 上会把噪声灌进接收链路。产品里通常用 DC-DC 升到 3.3~5 V 专用给 LED（MAX8614x 就要 3.1~5.5 V 的 LED 供电），并用旁路电容压住瞬态。
5. **采样率性价比**：心率 25~100 sps 足够，血氧研究再往上加。采样率每翻倍，LED 平均功耗同步翻倍——别为了"看起来专业"把 ODR 拉满。
6. **把 FIFO 当功耗杠杆**：FIFO 深 + 自主模式 + 中断读数，能让主控每秒钟只醒一两次。很多"省电芯片"实际功耗差异远小于"会不会睡"的差异。
7. **官方的原始数据接口比自己开会省药**：TI 有 BIO-SIGNAL SDK/GUI，ADI 有 Wavetool，汇顶有参考驱动——先跑官方 GUI 拿基线波形，再谈自研算法。

## 六、小结

独立 I2C/SPI PPG 芯片的选型逻辑其实就三板斧：**要什么功能（心率/血氧/心率变异性）→ 什么形态（模组还是可定制 AFE）→ 什么接口和功耗预算**。

值得记住的几个"阵营锚点"：

- **开箱即测**：MAX30102（生态）、BH1790GLC（功耗/极简）；
- **要自己做光学**：TI AFE44xx/AFE49xx（I2C/SPI 阵容最全）、ADI ADPD 系列（多模态天花板）；
- **腕部低灌注**：MAX86141 双通道 + SPI；
- **半集成的国产选项**：GH3011，IIC/SPI 任选，LED 外接、PD 内置、附算法。

至于没有接口的纯光学前端（OSRAM SFH7xxx、Broadcom APDS 等），它们适合"我什么都想自己搭"的场景，代价是整个 AFE 都得自己设计——那不是选芯片，是做芯片级的活儿。
